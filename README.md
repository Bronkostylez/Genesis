# GENESIS

**What would an AI do if you gave it a world it could completely reshape?**

GENESIS is an experiment in autonomous AI development.

A local language model is placed into its own isolated environment with only a few basic capabilities:

* 👁️ **View** — inspect its world
* ✏️ **Create** — create files and directories
* 🔧 **Edit** — modify existing files
* 🗑️ **Delete** — remove files
* ▶️ **Execute** — run its own Python programs

There is **no predefined goal, no technology tree and no fixed path**.

The AI decides what to build, what to change, what to test and what to do next.

The environment is recreated for every run, keeping the experiment separate from the host project.

## Stack

* **Python**
* **Ollama**
* **Qwen 2.5 7B**
* **Visual Studio**

## The idea

GENESIS starts with almost nothing.

From a handful of primitive interfaces, it can create increasingly complex structures — if it chooses to.

The experiment is intentionally open-ended:

> **Give an AI the ability to create. Then see what it creates.**
